# Руководство администратора — Coffeeshop ERP

## Вход в систему

1. Откройте браузер → введите адрес системы (например, `http://localhost:8080`)
2. Введите **Email** и **Пароль** администратора
3. Нажмите **«Войти»**

> **Забыли пароль?** Обратитесь к разработчику — самостоятельный сброс через UI не реализован в v1.0.

---

## Дашборд

Главная страница показывает за **текущий день**:

| Метрика | Описание |
|---------|----------|
| Выручка | Сумма всех оплаченных заказов |
| Кол-во чеков | Число завершённых заказов |
| Средний чек | Выручка ÷ Кол-во чеков |
| Маржа | (Выручка − Себестоимость) / Выручка |
| Тепловая карта | Загруженность по часам и дням недели |
| ABC-анализ | Топ продаваемых позиций меню |

Период можно изменить кнопками: **День / Неделя / Месяц / Произвольный**.

## Меню и товары

### Создание категории
**Меню → Категории → «+ Добавить»**
- Название, иконка (emoji), порядок сортировки

### Создание товара
**Меню → Товары → «+ Добавить»**
- Название, категория, базовая цена, фото
- Привязка к техкарте (рецепту)

### Модификаторы
Каждый товар может иметь группы модификаторов:  
**Товары → [товар] → Модификаторы → «+ Группа»**  
Пример: группа «Объём» с вариантами «250 мл (+0 ₸)», «350 мл (+100 ₸)», «450 мл (+200 ₸)»

### Стоп-лист
**Товары → [товар] → «Стоп-лист»** — вручную заблокировать позицию.  
Автоматически: когда остаток критичного ингредиента = 0, система сама блокирует связанные товары.

## Ингредиенты и склад

### Добавить ингредиент
**Склад → Ингредиенты → «+ Добавить»**
- Название, единица измерения, минимальный остаток (для оповещения)

### Приходная накладная (поступление товара)
**Склад → Приходы → «+ Новый приход»**
1. Выберите поставщика (или оставьте пустым)
2. Добавьте позиции: ингредиент, количество, цена за единицу
3. Нажмите **«Провести»**
   → Остатки и средневзвешенная себестоимость пересчитаются автоматически

### Списание
**Склад → Списания → «+ Новое»**
- Ингредиент, количество, причина (брак / пролив / угощение / проверка)

### Инвентаризация
**Склад → Инвентаризация → «+ Новая»**
1. Введите фактические остатки по каждому ингредиенту
2. Система покажет расхождения (излишки / недостачи)
3. Нажмите **«Завершить»** — остатки обновятся

---

## Техкарты (рецепты)

**Рецепты → «+ Новый»**
1. Укажите название рецепта
2. Добавьте ингредиенты с расходом на одну порцию
3. Привяжите к товару: **Рецепты → [рецепт] → «Привязать товар»**

При продаже товара система автоматически списывает ингредиенты по техкарте.

## Управление пользователями

**Настройки → Пользователи → «+ Добавить»**

| Роль | Права |
|------|-------|
| Администратор | Всё |
| Менеджер | Касса, склад, смены, отмены заказов |
| Бариста | Только касса, только своя смена |

### Смена PIN-кода бариста
**Пользователи → [бариста] → «Изменить PIN»**

### Деактивация сотрудника
**Пользователи → [сотрудник] → «Деактивировать»** (только администратор)

---

## Поставщики

**Склад → Поставщики → «+ Добавить»**
- Название, контактное лицо, телефон, БИН, адрес

---

## Смены

### Просмотр смен
**Смены → список** — время открытия/закрытия, выручка, количество чеков

### Операции с кассой
Добавление наличных в кассу / изъятие:
**Смены → [смена] → «Операция с кассой»**
- Тип: приход / расход / депозит / снятие
- Сумма, причина

---

## Отмена заказа / возврат

**Заказы → [заказ] → «Отменить»**
- Требуется PIN менеджера или администратора
- Необходимо указать причину
- Операция записывается в журнал аудита

---

## Аналитика

**Аналитика → раздел:**

| Раздел | Описание |
|--------|----------|
| Выручка по дням | Линейный график выручки за период |
| ABC-анализ | Товары по убыванию выручки и маржи |
| Тепловая карта | Часы и дни с максимальной загрузкой |
| Бариста | Выручка и средний чек по каждому сотруднику |

**Экспорт в Excel**: кнопка **«Скачать CSV»** доступна на каждом отчёте.

### Обновление аналитических данных
Если данные кажутся устаревшими:
**Аналитика → «Обновить кэш»** (обновляет материализованные представления)

---

## Бухгалтерия (опциональный модуль)

> Доступно только если в конфигурации включено `accounting.enabled = true`

**Бухгалтерия:**
- **Расходы** — ввод ручных расходов (аренда, коммуналка, прочее)
- **Категории расходов** — создание категорий
- **Журнал проводок** — автоматически заполняется при продажах и расходах

---

## Синхронизация и конфликты

**Система → Синхронизация**
- Список устройств и время последней синхронизации
- Неразрешённые конфликты (например, отрицательный остаток)
- Кнопка **«Разрешить»** — принять конфликтное значение

---

## Журнал аудита

Каждое чувствительное действие записывается:
- Отмена/возврат чека
- Изменение цен
- Открытие кассового ящика
- Изменение прав пользователей
- Вход/выход

**Система → Аудит** — поиск по сотруднику, типу действия, дате.
