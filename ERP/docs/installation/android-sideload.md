# Установка Coffeeshop POS на Android-планшет

> Приложение распространяется в виде `.apk`-файла — без Google Play Store.  
> Установка называется «sideload» (боковая загрузка).

---

## Требования

| Компонент | Минимум |
|-----------|---------|
| Android | 9.0 (API 28) или новее |
| RAM | 3 GB |
| Экран | 8" или больше (рекомендуется 10") |
| Хранилище | 200 MB свободного места |

---

## Способ 1 — Установка через USB-кабель (ADB)

Используется с ноутбука администратора.

### Шаг 1. Включите режим разработчика на планшете

1. **Настройки → О планшете → Номер сборки**
2. Нажмите **7 раз подряд** на «Номер сборки»
3. Появится сообщение: «Вы стали разработчиком!»

### Шаг 2. Включите отладку по USB

1. **Настройки → Для разработчиков**
2. Включите **«Отладка по USB»**
3. Подключите планшет кабелем к ноутбуку
4. На планшете появится запрос — нажмите **«Разрешить»** (отметьте «Всегда разрешать»)

### Шаг 3. Установите ADB (если не установлен)

```bash
# macOS
brew install android-platform-tools

# Ubuntu / Debian
sudo apt install adb

# Windows — скачайте Platform Tools с сайта Android и добавьте в PATH
```

### Шаг 4. Установите APK

```bash
# Проверьте что устройство видно
adb devices
# Должна появиться строка: <id>   device

# Установите приложение
adb install -r coffeeshop-pos.apk

# Флаг -r позволяет переустановить (обновить) поверх существующего
```

## Способ 2 — Установка с флешки через OTG

Если ноутбука нет рядом.

### Шаг 1. Подготовьте флешку

Скопируйте `coffeeshop-pos.apk` на флешку (USB или microSD).

### Шаг 2. Подключите флешку к планшету

Используйте **USB-C OTG-переходник** (USB-C → USB-A):
```
Флешка → [OTG-переходник] → Планшет (USB-C)
```

### Шаг 3. Разрешите установку из неизвестных источников

При первой установке Android попросит разрешение:

1. Откройте **файловый менеджер** (обычно предустановлен)
2. Перейдите на флешку и найдите `coffeeshop-pos.apk`
3. Нажмите на файл → «Установить»
4. Android спросит: **«Разрешить установку из этого источника?»**  
   Нажмите **«Настройки»** → включите разрешение → вернитесь назад → «Установить»

> Это одноразовое разрешение. После установки можно снова отключить.

## Первый запуск

1. Найдите «Coffeeshop POS» в списке приложений
2. Введите адрес сервера: `http://192.168.X.X:8080`  
   (IP-адрес ноутбука/сервера в локальной сети)
3. Введите PIN бариста (4-6 цифр)

## Обновление приложения

### Автоматическое уведомление (при наличии сети)

Приложение проверяет `GET /api/updates/latest` при запуске.  
Если доступна новая версия — появляется кнопка **«Обновить»**.

### Ручное обновление с флешки

```bash
# Новая версия — просто переустановите поверх (данные сохраняются)
adb install -r coffeeshop-pos-v1.1.0.apk
```

Или через флешку — тот же процесс, что и при первой установке.

## Решение проблем

| Проблема | Решение |
|----------|---------|
| `adb devices` показывает «unauthorized» | Разблокируйте планшет, нажмите «Разрешить» в диалоге |
| Нет OTG-поддержки | Проверьте настройки: Параметры USB → OTG → Включить |
| «Приложение не установлено» | Удалите предыдущую версию, затем установите новую |
| Приложение не видит сервер | Убедитесь что планшет и сервер в одной Wi-Fi сети |
| Экран гаснет во время работы | Настройки → Дисплей → Спящий режим → «Не отключать» |

---

## Режим киоска (опционально)

Чтобы планшет показывал только кассу и блокировал выход:

**Настройки → Специальные возможности → Закрепление экрана**  
или  
**Настройки → Безопасность → Закрепить экран**

После закрепления приложения выйти можно только с помощью PIN-кода.
