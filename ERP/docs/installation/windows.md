# Установка Coffeeshop ERP на Windows

## Требования

| Компонент | Минимум |
|-----------|---------|
| ОС | Windows 10 (64-bit) / Windows 11 |
| RAM | 4 GB |
| Диск | 500 MB свободного места |
| Дополнительно | PostgreSQL 15+ (для серверного режима) |

---

## Вариант 1 — Установка с флешки (рекомендуется)

### Шаг 1. Скопируйте установщик

Подключите флешку к компьютеру и скопируйте файл:
```
coffeeshop-erp-v1.0.0-windows-setup.exe
```

### Шаг 2. Запустите установщик

Дважды щёлкните по файлу. Windows SmartScreen может показать предупреждение:

> **«Windows защитила ваш компьютер»**

**Это нормально** — приложение не прошло подпись Microsoft (платная процедура).

Действия:
1. Нажмите **«Подробнее»**
2. Нажмите **«Выполнить в любом случае»**

![SmartScreen обход](../assets/smartscreen-bypass.png)

### Шаг 3. Следуйте инструкции установщика

- Выберите папку установки (по умолчанию `C:\Program Files\Coffeeshop ERP`)
- Нажмите **«Установить»**
- После завершения нажмите **«Готово»**

### Шаг 4. Первый запуск

Приложение запустится автоматически. Значок появится в системном трее (правый нижний угол).

При первом запуске введите данные подключения к серверу:
- **URL сервера**: адрес Go-сервера (например, `http://192.168.1.100:8080`)
- **Логин / Пароль**: данные администратора

---

## Вариант 2 — Портативный запуск (без установки)

Если нет прав администратора:

1. Скопируйте папку `erp-portable-windows/` с флешки на рабочий стол
2. Запустите `erp-server.exe` — откроется консоль с сервером
3. Откройте браузер и перейдите по адресу `http://localhost:8080`

---

## Настройка базы данных (для серверного режима)

Если PostgreSQL уже установлен:

```cmd
# В командной строке (cmd.exe)
set DATABASE_URL=postgres://postgres:ВАШ_ПАРОЛЬ@localhost:5432/coffeeshop
erp-server.exe --migrate
```

Если PostgreSQL не установлен — используйте встроенный SQLite-режим (только для одной кассы):

```cmd
erp-server.exe --sqlite --sqlite-path C:\erp-data\coffeeshop.db
```

---

## Брандмауэр Windows

При первом запуске Windows может запросить разрешение для `erp-server.exe`.  
Разрешите доступ для **частных сетей** (локальная сеть кофейни).

---

## Удаление

**Пуск → Параметры → Приложения → Coffeeshop ERP → Удалить**

Данные базы данных не удаляются автоматически.  
Они находятся в `C:\ProgramData\CoffeeshopERP\` (для SQLite-режима).

---

## Решение проблем

| Проблема | Решение |
|----------|---------|
| «Не удаётся запустить приложение» | Установите [Visual C++ Redistributable](https://aka.ms/vs/17/release/vc_redist.x64.exe) |
| Приложение не видит базу данных | Проверьте `DATABASE_URL` в настройках |
| Порт 8080 занят | Измените порт: `erp-server.exe --port 8081` |
| Значок не появился в трее | Перезапустите Проводник (Ctrl+Shift+Esc → Проводник → Перезапустить) |
